[2026-10-14] マイページ: アカウント表示の重複解消・サインアウト/削除を最下部へ移動
--------------------------------------------------------------------------------
変更ファイル: ios/Cycle/Features/Settings/Views/SettingsView.swift
内容:
  1) アカウント欄の表示（④）
     Before: 1行目「名前 ?? メール」、2行目に常にメールを表示。
             名前がないユーザー（Apple は初回サインイン時しか名前を渡さない）
             ではメールアドレスが2行続けて表示されていた。
     After:  名前あり → 1行目に名前、2行目に小さくメール。
             名前なし → メールを1行だけ表示。
             名前がある場合はアバターを名前の頭文字（茶色の丸）にする。
             名前がない場合は従来の人型アイコンのまま。
             表示部分は accountProfileRow として切り出し。
  2) サインアウト・アカウント削除の位置（⑤）
     Before: 「アカウント」セクション内（画面の一番上）に赤いボタンが2つ並ぶ。
     After:  「アカウント」セクションはユーザー情報のみにし、2つのボタンは
             「サポート」の下に見出しなしの独立セクションとして移動
             （Release ビルドでは画面の最下部。DEBUG では下に開発者オプションが続く）。
             確認アラート・accessibilityIdentifier("delete_account_button")は変更なし。
目的: 同じ文字列の重複表示をなくし、取り消しにくい操作が最初に目に入らない
      一般的な設定画面の並びにするため。
結果: ビルド成功。iPhone 16 Pro (iOS 18.1) シミュレータで
      アカウント欄がメール1行になったこと、ボタンが最下部に移ったことを確認。
      ※ 名前ありユーザーの頭文字アバターは、DEBUG のモックユーザーに名前がないため
        画面上では未確認。

--------------------------------------------------------------------------------

  - ios/Cycle/Features/Tasks/Views/TaskArchiveView.swift（削除）

  - ios/Cycle/Shared/DesignSystem/ComponentCatalog.swift
  - ios/CycleTests/CycleTests.swift
  - ios/CycleUITests/CycleUITests.swift
内容:
  1) 画面構成
     Before: 見出し「タスクリスト」の下に、全期間の未完了→完了タスクを1本のリストで表示。
     After:  ジャーナルと同じく、見出しに年月・「今日」ボタン、その下に週カレンダー。
             選んだ日のタスクだけを「未完了 → 完了 → 見送ったタスク」の順で表示。
             タスクがある日は週カレンダーにドットを表示。空の日は「この日のタスクはありません」。
  2) 日付の決め方（オーナー決定）
     - タスクは作成した日に固定。未完了のまま日をまたいでも今日へ繰り越さない。
       完了しても作成日に残る。
     - 見送ったタスクは見送った日に、理由・「見送り」バッジ・「再開」スワイプ付きで表示。
       再開すると未完了に戻り、作成日の一覧へ戻る。
     - ＋ボタンで追加したタスクは、選択中の日付に入る（過去・未来の日にも追加できる）。
     - 旧アーカイブに入っている完了タスクも、作成日の一覧に「完了」バッジ付きで表示。
  3) アーカイブ機能の廃止
     - 完了タスクのスワイプ「アーカイブ」と、メニューの「アーカイブ」画面を削除。
     - アーカイブ画面にあった「ワードで検索」は、右上メニューの「検索」へ移動。
       全期間の未完了・完了・見送りタスクを日付ごとに表示し、タップでその日へ移動する。
  4) メニュー
     Before: 並び替え / アーカイブ / テンプレート管理 / 最近削除した項目
     After:  検索 / 日付選択 / 並び替え / テンプレート管理 / 最近削除した項目
             （並び替えは選択中の日のタスクの中で行う）
  5) ホーム画面のタスク表示も同じルール（作成日で振り分け）に統一。
     Before: 今日には全期間の未完了タスクを表示。
  6) 週カレンダー（WeekCalendarView）をジャーナルとタスクリストで共用できるよう汎用化。
     ジャーナルの見た目・動作は変更なし。
  7) 一覧の末尾が右下の＋ボタンに隠れないよう、下に余白を追加。
  8) 見送り画面の説明文を「今日の日付に『見送ったタスク』として残します」に変更。
目的: タスクを日付で管理できるようにし、別画面のアーカイブを不要にするため（オーナー要望）。
データ: 保存形式は変更なし。見送ったタスク・旧アーカイブの完了タスクは従来どおり
        task_archives.json に保存される。日付の判定には既存の createdAt / skippedAt を使用。
結果: ビルド成功。iPhone 16 Pro (iOS 18.1) シミュレータで以下を確認。
      日付切り替え・「今日」ボタン、過去日への追加、見送り（見送った日へ移動）、
      再開（作成日へ戻る）、検索とタップでの日付移動、ジャーナルの週カレンダー。
      ユニットテスト 148件すべて成功（日付別表示・過去日への追加・見送り日の表示・
      日付内の並び替えのテストを追加）。
      UIテスト（検索、見送り→再開の流れ）2件成功。

[2026-10-14] タスクの「見送る」機能を削除
--------------------------------------------------------------------------------

  - ios/CycleTests/CycleTests.swift

  - docs/public/screenshots/task-unfinished-*.png（削除）
内容:
  Before: 未完了タスクを左スワイプ「見送る」→ 理由を入力 → 見送った日の
          「見送ったタスク」欄に移動。そこから「再開」で未完了に戻せた。
  After:  見送りという状態そのものを廃止（オーナー判断:「見送るならチェックを
          つけなければいいだけ」）。
          - スワイプの「見送る」ボタン、見送り画面、「見送ったタスク」欄、
            「再開」、検索結果の「見送り」バッジを削除。
          - 既存データの扱い: 1.0.11 で見送ったタスクがある端末では、読み込み時に
            普通の未完了タスクへ戻し、作成日の一覧に表示する。
            見送り理由は消さずに「注意点」の末尾へ「見送り理由: …」として残す。
            サーバー上のタスク（見送り中も pending のまま残っていた）とは
            同じ ID のまま揃う。
目的: 操作と状態を減らして、タスクを「やった / まだ」だけで直感的に扱えるようにするため。
結果: ビルド成功。ユニットテスト 145件すべて成功（見送り関連テストを、既存データの移行
      テスト3件に置き換え）。iPhone 16 Pro (iOS 18.1) シミュレータで、タスクの
      左スワイプが「プレビュー / 編集 / 削除」の3つになったことを確認。
      ※ 既存の見送りデータからの移行は、ユニットテストでのみ確認（実機データでは未確認）。

[2026-10-15] タスクに「日付」と「締切時刻（終日あり）」を入力できるようにした
--------------------------------------------------------------------------------
変更ファイル:
  - ios/Cycle/Features/Tasks/Model/Task.swift
  - ios/Cycle/Features/Tasks/ViewModel/TaskViewModel.swift
  - ios/Cycle/Features/Tasks/Views/Components/TaskScheduleFields.swift（新規）
  - ios/Cycle/Features/Tasks/Views/Components/TaskRow.swift
  - ios/Cycle/Features/Tasks/Views/TaskNewEntryView.swift
  - ios/Cycle/Features/Tasks/Views/TaskEditView.swift
  - ios/Cycle/Features/Tasks/Views/TaskPreviewView.swift
  - ios/Cycle/Features/Tasks/Views/TaskSearchView.swift
  - ios/CycleTests/CycleTests.swift
内容:
  1) 入力（新規作成・編集の「基本情報」）
     「詳細」の下に「日付」欄を追加。
       - 日付: カレンダーから選択（新規作成時は、タスクリストで選択中の日が初期値）
       - 終日: スイッチ（初期値 ON）
       - 締切: 終日を OFF にすると表示。時刻を選択（初期値は「次のちょうどの時刻」）
     編集で日付を変えると、そのタスクは新しい日の一覧（未完了の末尾）へ移る。
  2) 表示
     - 一覧の行: 締切時刻があるタスクは「🕐 18:00まで」を表示。
       未完了のまま締切を過ぎたら赤字で「期限切れ・18:00まで」。
       終日のタスクは、その日が終わっても未完了なら「期限切れ」。
     - プレビュー: 「日付」欄に「10月15日(木) 終日 / 18:00まで」を表示。
  3) データ
     - TaskItem に scheduledDate（タスクの日付）と deadline（締切日時。空なら終日）を追加。
     - 既存のタスクは scheduledDate が空のため、これまでどおり作成日に表示する
       （期限切れ表示もしない）。古い保存データもそのまま読み込める。
     - 前回の「選択日に追加すると createdAt をその日にずらす」処理は廃止し、
       createdAt は本当の作成日時に戻した。
目的: タスクを日付・締切で管理できるようにするため（オーナー要望）。
結果: ビルド成功。ユニットテスト 149件すべて成功（日付・締切・期限切れ・
      旧データ読み込みのテストを追加）。iPhone 16 Pro (iOS 18.1) シミュレータで、
      新規作成での日付欄・終日OFFで締切欄が出ること、一覧の「01:00まで」表示、
      編集画面に日付・締切が引き継がれることを確認。
      ※ 赤字の「期限切れ」表示はユニットテストでのみ確認（画面では未確認）。
