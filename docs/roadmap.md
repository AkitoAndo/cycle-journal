# Product Roadmap

## ゴール（2026-10-23 決定）

**2026年12月31日に、毎週使う人（WAU）を300人にする。**

- WAU の定義: その週に1回以上、日記・タスク・コーチのいずれかを使った人
- 今の WAU は測れていない（アプリにアクセス解析がなく、サーバーで見えるのはサインインした人だけ）。
  途中の目標値は仮。11月上旬に今の人数が分かった時点で見直す。
- 目安: 日記アプリで使い続ける人は入れた人の2〜3割ほどとされるため、
  毎週150人前後の新しい人に入ってもらう必要がある（仮定）。

### 逆算した計画

| 期間 | やること | この時点の目標 |
|---|---|---|
| 〜10/31 | WAU の測り方を決めて計測の準備をする。App Store Connect でダウンロード数を調べる | 今の人数をつかむ |
| 〜11/9 | 計測を入れたバージョンをリリースする（たまっているタスク機能の PR #151〜#154 も一緒に出す） | 計測が動き出す |
| 11/10〜11/30 | 使い続けてもらうための改善: リマインダー通知（日記・タスクの締切）、初めて使う人向けの案内 | WAU 100人（仮） |
| 12/1〜12/20 | 人を集める:「1年のふりかえり」をテーマにした発信、App Store の説明文・スクリーンショットの見直し、SNS | WAU 200人（仮） |
| 12/21〜12/31 | 数字を見ながら調整する（年末のふりかえり需要が一番高まる時期） | **WAU 300人** |

### 未決定のこと

- 計測ツールを何にするか（Firebase Analytics、TelemetryDeck など）: CTO と相談
- 広告にお金をかけるか: かけない場合、12月の集客は発信と App Store の見直しが中心

> 以下の AS-IS / TO-BE は 2026-03 時点の記録。

## AS-IS（現状 / 2026-03時点）

### iOS
- Journal: ローカルCRUD完成（タグ管理、検索、週間カレンダー、ソフトデリート）
- Tasks: ローカルCRUD完成（ふりかえり項目: fact/insight/nextAction、並び替え、アーカイブ）
- Coach: チャットUI・セッション履歴・日記選択画面が動作。API接続済（requiresAuth: true）
- Auth: Sign in with Apple のUI実装済。サーバー検証エンドポイント接続済
- Settings: UI骨格のみ（通知・エクスポートは未実装）
- データ保存: JSONファイル（DocumentsDirectory）+ UserDefaults + サーバー同期（タスクCRUD・セッション履歴）
- E2Eテスト: Cloud Run APIに対する9テスト通過

### Backend
- FastAPI + Cloud Run: 全13エンドポイント実装・デプロイ済（dev環境）
- Firestore: データベース + 複合インデックス2つ作成済
- Terraform: 16リソース全てapply済・state管理下
- Docker: uvベースのコンテナビルド（linux/amd64）
- Apple JWT認証: JWKS取得・キャッシュ・検証ミドルウェア実装済
- コーチAI: SYSTEM_PROMPT（大樹メタファー + 7ルール）+ Vertex AI Claude + LangGraphフロー
- テスト: pytest 10件 + iOS E2E 9件 通過
