## 決定事項（2026-10-24 オーナー決定）

1. **下タブは3つ**: ホーム / コーチ（中央の大樹ロゴ）/ 記録
2. **日記とタスクは「記録」タブにまとめる**（日付で両方を見る）
3. **マイページはホーム右上のアイコンから開く**（タブからは外す）
4. **見た目は、色（生成り×茶）はそのままで、形を iOS 17 の標準アプリに合わせる。ホームだけでなくアプリ全体を通して**
   - 大きなタイトル、角丸でまとめたリスト、標準の書体、行末の「>」
   - iOS 26 のガラス表現は使わない（どの iOS でも同じ見た目）

ホームの見出しは日付（大きく「10月24日」、下に曜日）。挨拶は出さない。

## なぜ3つか

- Treow の循環は「書く → 話す → 一歩 → ふりかえる」。入口はホーム1つで足りる。
- 日記とタスクはどちらも「日付で見る記録」で、画面の形がほぼ同じ（週の帯＋一覧＋追加ボタン）だった。分ける理由がない。
- タブが減ると、中央の大樹ロゴ（コーチ）がいちばん目立つ。「コーチと話す」がこのアプリの中心だと伝わる。
- 設定は毎日開くものではない。タブに置く必要がない。

## 各タブの役割

| タブ | 役割 | 入口 |
|------|------|------|
| ホーム | 今日やることの入口。今日の問いかけ（書く / 話す）、今日の予定、今日の一歩、今週の樹と1週間の帯、週のふりかえり | 右上「…」: 予定を追加 / 今日のタイムライン。右上の人のアイコン: マイページ |
| コーチ | 呼吸を整える、話しかける、日記から話す、週のふりかえり、履歴 | 右上: 履歴 |
| 記録 | 日付を選んで、その日の日記と一歩を見る・書く・直す | 右上「…」: 検索 / 日付選択 / タグ管理 / テンプレート管理 / 並び替え / 最近削除した項目 |

## 「記録」タブの形（案）

```
┌──────────────────────────────┐
│ 10月24日                 …   │ ← 大きなタイトル（選んだ日）。タップで月カレンダー
│ 土曜日                       │
│  月  火  水  木  金  土  日   │ ← 1週間の帯（ホームと同じ部品）
│  19  20  21  22  23 (24) 25  │
│                              │
│ 日記                         │ ← 見出し
│ ╭──────────────────────────╮ │
│ │ 同僚とランチに行った…     │ │ ← 角丸でまとめたリスト
│ │ 12:00  仕事  感謝        > │ │
│ ├──────────────────────────┤ │
│ │ 朝ランニングをした…       │ │
│ ╰──────────────────────────╯ │
│                              │
│ 一歩                         │
│ ╭──────────────────────────╮ │
│ │ ○ 週報を書く   🕐18:00まで >│ │
│ │ ✓ ジムに行く               │ │
│ │ ＋ 一歩を追加              │ │
│ ╰──────────────────────────╯ │
│                        (＋)  │ ← 日記を書く
└──────────────────────────────┘
```

- 1画面に「日記」と「一歩」の2つのリスト。どちらも角丸でまとめた形。
- 右下の「＋」は日記を書く（いちばん多い操作）。一歩はリストの最後の行から追加する（ホームと同じ）。
- 行のスワイプ（編集・削除・引用・プレビュー）は今の日記一覧・タスク一覧と同じ。
- 日記の検索とタスクの検索は、右上メニューの「検索」からひとつの画面で両方を探す（まずは2つの検索画面を切り替える形でもよい）。
- 並び替え（ドラッグ）は、メニューから入ると一歩のリストだけが並び替えになる。

## 進め方（1 PR ずつ）

1. **タブを3つにする**: ContentView のタブ定義を変え、マイページをホーム右上のアイコンから開くシートにする。記録タブは暫定で「日記 / 一歩」の切り替えで既存の2つの一覧を出す。 — **2026-10-24 実装済み**（PR: feature/three-tabs）
2. **記録タブ**: 日記一覧とタスク一覧を1画面にまとめる。メニューの統合、検索の統合。 — **2026-10-24 実装済み**（PR: feature/records-tab）。検索は「日記を検索」「一歩を検索」の2つの画面のまま（統合は後回し）。
3. **コーチタブ**: iOS 17 の形に（大きなタイトル、ボタンの形、履歴の一覧）。 — **2026-10-24 ホーム画面は実装済み**（PR: feature/coach-tab-ios17）。履歴（SessionHistoryView）と対話画面は実装単位5で。
4. **マイページ**: 設定画面を iOS 17 の形に（すでに Section ベースなので小さな調整）。
5. **シート類**: 日記・タスクの作成/編集、週のふりかえりの材料選択、対話画面を同じ形にそろえる。
6. **オンボーディング・ドキュメント**: タブ名の変更を U-01、`docs/README.md`、スクリーンショット（`docs/public/screenshots/`）、UI テスト（`tab_Journal` などの識別子）に反映。

## 非対象

- 機能の削除。日記・タスクの機能（タグ、テンプレート、並び替え、検索、ゴミ箱、引用）はすべて残す。置き場所が変わるだけ。
- 色の変更。生成り×茶のまま。

## 影響するもの

- UI テスト・Maestro のタブ識別子（`tab_Journal` / `tab_Tasks` / `tab_MyPage`）
- `docs/public/screenshots/` のスクリーンショット（4タブ時代のもの。12月の App Store 見直しで撮り直す）
