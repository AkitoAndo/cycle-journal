## 初回リリース向け説明文

はっきりしない不安がある。
動き出したいのに、続かない。
考えすぎて、頭の中が散らかっている。

Cycle Journal は、日記、AIコーチ、タスク、振り返りをひとつにつなげる自己理解のためのアプリです。

書いたことを見返し、AIコーチと対話し、今日できる小さな行動に変える。
その流れをくり返すことで、自分の考えや感情、行動のパターンが少しずつ見えてきます。

### 主な機能

- 日記: 気持ちや出来事を短く記録
- AIコーチ: 書いた内容や今の悩みをもとに、内省を助ける問いを返します
- タスク: 気づきを今日の小さな行動に変換
- 呼吸セッション: 対話前に、短い呼吸で気持ちを整えます
- 振り返り: 過去の記録から、自分の変化を見返せます
- 認証と同期: アカウントに紐づけてデータを扱えます

Cycle Journal は、答えを急がせるアプリではありません。
自分の状態を言葉にし、無理のない一歩を見つけるための静かな場所です。

## 受け入れ条件

- App Store Connect の各入力項目に転記できる粒度になっている。
- 未実装機能を主機能として訴求していない。
- 医療効果、診断、治療、メンタル改善の断定表現を含まない。
- 課金導線と Legal URL の審査要件チェックと矛盾しない。
- スクリーンショットの実画面と説明文の機能範囲が一致している。

## 呼吸体験を強く訴求する場合の候補

スクリーンショットや初回体験で呼吸セッションを前面に出す場合は、以下の訴求を使う。

- 気持ちを整える呼吸セッション
- AIコーチとの対話前に、呼吸を整える導線
- 記録、対話、行動、呼吸をまとめたセルフケア体験

## 呼吸体験を強く訴求する場合のアプリ名候補

Cycle — AIコーチ・呼吸・日記・タスク管理

## 呼吸体験を強く訴求する場合の説明文候補

はっきりしない不安がある。
動き出したいのに、続かない。
考えすぎて、頭の中が散らかっている。

それはツールが足りないのではなく、
自分と向き合う時間が足りなかっただけかもしれません。

Cycleは、
考える・整える・動く・振り返るを
ひとつにつないだ自己成長アプリです。

そのときの自分に合わせて、
必要な機能からすぐに使えます。

### AIコーチと話す

悩みや目標をAIに話すだけで、頭の中が整理されます。
問いかけを通して、自分の中にある感情や思考に気づけます。
話し終えたとき、次の一歩が見えています。

### 気持ちを整える瞑想

考えすぎて動けないとき、まず呼吸を整えましょう。
瞑想で意識を今に戻すことで、本当に大切なことが見えやすくなります。

### タスクで行動に変える

やることを整理して、今日ひとつだけ動く。
それだけで、止まっていた毎日が動き出します。

### 日記で自分を知る

短くていい、うまくなくていい。
書いた言葉はAIコーチとの対話にもつながり、
気づきが積み重なっていきます。

### 振り返りで成長を確かめる

1週間前、1ヶ月前の自分と比べてみてください。
記録が積み重なるほど、
自分の変化がはっきり見えてきます。

### 使い方

まず話したいなら、AIコーチを。
気持ちを落ち着けたいなら、瞑想を。
動きたいなら、タスクを。
書きたいなら、日記を。

Cycleは、そのときのあなたに合わせて使えます。
