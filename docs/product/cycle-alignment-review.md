# 機能は Treow の理念と循環になっているか（2026-10-24 時点の点検）

2026-10-23〜24 に進めた変更（PR #155〜#164: ロードマップのゴール、1週間のふりかえり、ホーム刷新、3タブ、記録タブ、iOS 17 / Claude 風のデザイン）を、Treow の理念と循環モデルに照らして点検した。結論を先に書く。

> **循環の「器」はそろったが、「矢印」が3本欠けている。**
> 書く・話す・一歩・ふりかえるの4つの場所はホーム1画面から入れるようになった。しかし、対話で見つけた一歩がタスクに渡らず、週のふりかえりの成果（今週の一文・来週の一歩）がどこにも残らず、次の週に引き継がれない。いまの Treow は「4つの機能が並んでいる」状態で、「循環している」状態ではない。

## 1. 照らし合わせた理念

| 出典 | 理念 |
|------|------|
| `docs/README.md` | 日記を書き、コーチとの対話で自己理解を深め、小さな行動につなげる。**最終的にはアプリがなくても自分と向き合える力を育てる** |
| `docs/product/cycle-model.md` | 大樹モデル。土（環境・記憶）→ 根（価値観・感情）→ 幹（意志）→ 枝（思考）→ **葉（日常の行動・表現）→ 実（成果・気づき）**→ 空 → 土へ還る。水が循環を支える |
| `docs/product/coach-design.md` | 会話の流れは 導入 → 深掘り → 統合 → 実行 → **ふりかえり**。答えを与えず、問いで気づきを促す。急がせない |
| `docs/backlog/ux/U-03-weekly-cycle.md` | 1週間を単位に「日記 → 対話 → 一歩 → ふりかえり → 次の週」をつなぐ。書かなかった日を責めない |

## 2. 循環の段階ごとの対応

◎ = 理念どおりに動いている / ○ = 動くが理念の一部が欠ける / △ = 入口だけ / × = ない

| 段階 | 大樹モデル | 今の機能 | 評価 | 欠けているもの |
|------|-----------|---------|------|---------------|
| 整える | 水 | コーチタブの呼吸セッション（ロゴをタップ） | ○ | 呼吸の後に「書く・話す」へ自然に進む流れがない（ログが残るだけ） |
| 書く | 葉（日常の表現） | 日記（記録タブ、ホームの「書く」）。タグ、引用、検索、ゴミ箱 | ◎ | — |
| 話す | 根・幹（感情・価値観・意志） | コーチ（話しかける / 日記から話す）。LangGraph で感情分析と問い | ○ | セッションの**まとめ**（テーマ・気づき・次の一歩）がない（C-10 未実装）。話した内容が「実」として残らない |
| 一歩 | 葉・枝（行動・可能性） | タスク（記録タブの「一歩」、ホームの「今日の一歩」）。完了時の事後情報（事実・気づき・次の一手） | ○ | **対話 → 一歩の受け渡しがない**（U-03 実装単位1 未着手）。いまの一歩は手で入力する ToDo と同じ |
| ふりかえる | 実（成果・気づき） | 週のふりかえりの入口（ホーム・コーチタブ）。材料を選んでコーチと話す | △ | 対話の終わりに「今週の一文」「来週の一歩」を決める仕組みがない。ふりかえった結果が残らない |
| 還る・次へ | 空 → 土（次の循環） | 今週の樹（記録で葉がつく、週が変わると芽に戻る） | × | 「先週の一文」を次の週の始まりに見せる仕組みがない。樹の葉は数えるだけで、実（気づき）にならない |
| アプリなしで向き合える力 | 理念の到達点 | — | × | コーチなしで回る形がない。コーチはサインインが必要なので、サインインしない人の循環は「書く」で止まる |

## 3. 画面ごとの評価

**ホーム（今日）**
- 問いかけ「今日は、どんな一日だった？」から「書く」「話す」に1タップで入れる。理念の入口として正しい。
- 「今日の一歩」はタスクの一覧であって、「コーチと決めた一歩」ではない。見出しの言葉だけが先に理念に追いついている。
- 「今週の樹」は記録の**数**を葉にしている。「たくさん書いた週が良い週」と読めるので、理念（質と気づき）とずれる危うさがある。葉に上限（21枚）を置き、枯れる表現を避け、説明文を消したのはその緩和策で、根本の答えではない。本来は「葉＝行動、実＝気づき」と分けるべき（第4節）。

**コーチ**
- 「話しかける」が主役で、呼吸 → 話すの順に並ぶ構成は理念に合う。
- ただし対話の出口（まとめ）がないため、話して終わる。会話フローの「統合 → 実行 → ふりかえり」のうち、実行とふりかえりはアプリの外で起きる。

**記録**
- 日付を選んで日記と一歩を1画面で見られる。「その日に何を書き、何をしたか」を一緒に見られる点は循環を意識している。
- 一歩の機能（テンプレート・並び替え・締切・検索）は汎用 ToDo の方向に厚い。理念の「小さな一歩」には重い。削る必要はないが、増やさない線を引くべき。

**タブ**
- ホーム / コーチ / 記録 の3つで、中央の大樹ロゴがコーチ。「話すことが中心」と伝わる。理念に合う。

**マイページ**
- 設定として過不足なし。理念との関係は薄い。

## 4. 理念とずれる、または危ういところ

1. **循環が閉じていない。** 対話 → 一歩、ふりかえり → 一文、一文 → 次の週、の3本の矢印がない。これが最大のずれ。4つの機能はそろったが、ユーザーから見ると「日記アプリ」「ToDo」「チャット」が並んでいる。
2. **樹が「量」を測っている。** 記録数を葉にする今の形は、継続の動機にはなるが、理念の「気づき」を測っていない。葉（行動）と実（気づき）を分け、実はセッションのまとめや週の一文から結ぶ形にしないと、樹は「ログの可視化」で止まる。
3. **「アプリなしで向き合える力」に向かう機能がない。** いまの設計はコーチに向かう矢印ばかりで、コーチから離れる矢印がない。たとえば「今週はコーチなしでふりかえる（問いだけ出して自分で書く）」「コーチの問いを日記のテンプレートにする」のような、自分で回せる形が必要。
4. **サインインの壁。** コーチはサインインが必要。サインインしない人には循環の半分（話す・ふりかえる）がない。ホームの「話す」を押してサインインを求められる体験は、理念の入口としては硬い。
5. **コーチの最初の一言が機械的。** 週のふりかえりは「今週をふりかえりたいです」を自動送信して始まる。コーチ設計の「静けさ」「問いかけで終わる」には合うが、ユーザーの言葉でない発言が履歴に残る。
6. **細部の言葉。** タブは「記録」、中身は「日記」と「一歩」、コーチのボタンは「日記から話す」、設定は「タスク」。「一歩」と「タスク」が混在している（マイページの「完了時に事後情報を記入」など）。

## 5. 次に埋めるべき矢印（優先順）

1. **対話 → 一歩**（U-03 実装単位1 / C-10）: セッションのまとめで「次の一歩」を出し、「タスクに追加」で一歩にする。これで「一歩」が理念どおりの意味になる。
2. **ふりかえり → 今週の一文・来週の一歩 → 次の週**（U-03 実装単位3の残り・5）: ふりかえりの終わりに一文と一歩を残し、次の週のホームに出す。樹に「実」を結ぶのもここ。
3. **コーチなしで回る形**（新規）: 週のふりかえりに「問いだけで、自分で書く」モードを置く。サインイン前でも循環が一周できる。理念の到達点に向かう最初の一歩。
4. **言葉の統一**（U-04 実装単位6 と合わせて）: 「タスク」を「一歩」に寄せる。

1〜2 は 11/10〜11/30 の「使い続けてもらうための改善」の範囲に入れるのが妥当。3 は12月の「1年のふりかえり」施策の土台にもなる。
