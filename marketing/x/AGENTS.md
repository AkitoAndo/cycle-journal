# Marketing writing instructions

- 外部へ発信する日本語のプロフィール、投稿、引用コメント、返信、リリースノートは、`marketing/x/`配下のMarkdownファイルで作成する。
- 日本語ルールには、一般文書向けの`textlint-rule-preset-japanese`を使用する。技術文書向けプリセットは使用しない。
- 発信用文章を作成または更新した後は、リポジトリのルートで`npm --prefix docs run lint:text:external -- <対象ファイル>`を実行する。
- textlintのエラーを解消してから、文章をユーザーへ提示する。ルールを無言で無効化しない。
- textlintの通過だけで文章を完成としない。引用文は一文か二文に収め、抽象的な要約や整いすぎた説明を避ける。
- 引用文では、投稿を読んだ人がその場で返したような短い反応を優先する。
- 外部向けの本文は、短く落ち着いた「です・ます調」で統一する。第三者の原文は変更しない。
- 自動修正を使用した場合は、意味や温度が変わっていないかを人が読み直す。
- Hinaka本人の実体験を創作しない。Treowは、Hinakaが開発しているジャーナルアプリとして扱う。
- 大量の投稿案を先に作らず、最大3案を目安にHinakaと壁打ちする。
- メンタルヘルスの診断、治療、症状改善を想起させる表現を避ける。
