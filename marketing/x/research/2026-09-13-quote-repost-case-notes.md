# 引用リポストの詳細事例メモ

- 調査日: 2026-09-13
- 対象: 日記、ジャーナリング、手帳、ノート、記録習慣に関する日本語投稿
- 用途: Hinakaの引用リポストを、事例に基づいて組み立てるための記録

## このメモの使い方

各事例を、次の3層に分けて記録する。

1. 観察事実: 投稿の内容、形式、反応数
2. 解釈: 引用側の文章が果たしている役割
3. Hinakaへの変換: 採用する構造と、採用しない表現

反応数には、引用者の規模、元投稿の広がり、画像、投稿時刻なども影響する。
文章だけを成功の原因とは判断しない。

実際の運用では、[引用リポスト記録テンプレート](../templates/quote-repost-record.md)を複製して使用する。

## 記録項目

今後の事例も、次の項目で記録する。

| 項目 | 記録する内容 |
|---|---|
| 関係 | 第三者、同業、作り手、版元、利用者など |
| 元投稿の形式 | 短文、記事、画像、質問、利用報告など |
| 引用までの時間 | 同日、翌日、数週間後など |
| 反応トリガー | 投稿内のどの一点を拾ったか |
| 主な機能 | 驚き、具体化、回答、続報、作り手の応答など |
| 価値差分 | 元投稿になかった何を一つ足したか |
| 文の順番 | 各文の役割を、先頭から順に記録する |
| 口調 | 話し言葉、温度、断定、宣伝を5段階で記録する |
| 根拠 | 写真、数字、経験、役割固有の情報、外部記事など |
| 行動喚起 | 読む、試す、商品を見るなど。何も求めない場合も記録する |
| メディア | 画像やリンクが、証拠、手順、完成例のどれを担うか |
| 結果 | 表示、いいね、リポスト、保存、返信と、各比率 |
| Hinaka適合 | 採用、要調整、不採用と、その理由 |
| 再現骨格 | 固有の言葉を外し、機能と順番だけを残した型 |
| 失敗条件 | どのような場合に使わないか |

話し言葉、温度、断定、宣伝の点数は、反応の良しあしを示す数字ではない。
1は弱く、5は強いことを表す。

## 事例01: うにの部屋

- 引用投稿: [うにの部屋の引用](https://x.com/rechi_sub/status/2003623232457572407)
- 元投稿との関係: 関連アカウントの可能性はあるが、公開表示だけでは断定できない

- 引用までの時間: 翌日
- 引用側の短い抜粋: 「これ信じてるから高校生の時からバレットジャーナル付けてる。」

### 観察事実

- 反応トリガー: 目標を言葉にすると行動へつながる、という元投稿の主張
- 主な機能: 経験による裏付け
- 価値差分: 継続期間、1冊にまとめる方法、年末の確認、達成割合を追加
- 根拠: 高校生の頃からの経験と、7割から8割という本人申告
- 文の順番: 即時同意、継続期間、具体的な方法、数字を含む結果
- 口調: 話し言葉4、温度3、断定4、宣伝1
- 行動喚起: 明示なし
- メディア: 引用側にはなし。文章だけで方法を説明している
- 結果: 3,816,323表示、35,859いいね、3,367リポスト、17,148保存、48返信
- 比率: 保存÷いいね47.8%、リポスト÷いいね9.4%、いいね÷表示0.94%

### 解釈

最初の一文で元投稿を信じる理由を示している。
その後は、一般論ではなく、自分の方法を順番に説明している。
最後に数字を置くため、体験談として強く見える。

### Hinakaへの変換

- 採用判断: 不採用
- 合う点: 同意の直後に具体的な情報を置く順番
- 変える点: 長期経験と達成割合は使わない
- 再現骨格: `[短い同意]＋[確認できる具体的な方法]`
- 使える条件: Treowの仕様や公開済みの使い方を、事実として補足できる場合
- 失敗条件: 経験、期間、効果を作らなければ文章が成立しない場合

## 現在の候補投稿への具体的な適用

- 候補投稿: [𝓤｜ゆぅの日記投稿](https://x.com/u_note_log/status/2097639800765563172)
- 元投稿の形式: 8日分の日記を見せる4枚の画像
- 元投稿の中心: 来年使う1日1ページの手帳に備え、現在のノートで似た形式を試している
- 引用側が拾える一点: 新しい手帳を使い始める前に、今のノートで書き方を試していること
- 拾わない点: 日記全体の美しさ、継続の効果、本人の心理状態

### 推奨する反応

> 来年の手帳を使う前に、今のノートで書き方を試してるのいいな。

### 反応の分解

- 反応トリガー: 来年の道具へ切り替える前に、書式だけを先に試している
- 主な機能: 具体的な一点への発見
- 価値差分: 元投稿の行動を、準備の工夫として短く言い直す
- 文の順番: 時間の条件、具体的な行動、その場の反応
- 文字の温度: 話し言葉4、温度2、断定1、宣伝1
- 語尾: 「いいな」で止め、教訓にしない
- 行動喚起: なし
- URL、タグ、Treowへの言及: すべてなし
- 実体験: 含めない
- 効果表現: 含めない

### 前の案との差

前の案は、「自分に合う書き方を探す」という抽象的なまとめだった。
この表現は、多くの日記投稿へそのまま付けられる。

今回の案は、「来年の手帳」「今のノート」「先に試す」という元投稿固有の要素を残している。
別の投稿へ流用しにくいため、本人がその投稿へ返した言葉に見えやすい。

### この型の再現手順

1. 投稿から、他の投稿にはない名詞を二つ選ぶ。
2. 投稿者が行った動作を一つ選ぶ。
3. 名詞と動作を一文に入れる。
4. 最後を、短い感想で止める。
5. 教訓、効果、一般論を追加しない。

この投稿では、名詞が「来年の手帳」と「今のノート」、動作が「書き方を試す」、反応が「いいな」に当たる。

## Hinaka用の引用作成手順

### 1. 元投稿を選ぶ

次のうち、3つ以上を満たす投稿だけを候補にする。

- 画像、記事、手順、具体的な経験のいずれかがある
- Hinakaが固有の名詞を二つ拾える
- 一つの動作や工夫へ反応できる
- 実体験を作らずに書ける
- メンタルヘルスの効果を扱わずに書ける
- Treowを出さなくても引用する意味がある

### 2. 反応トリガーを一つ決める

投稿を要約せず、「どこを見て手が止まったか」を一つだけ書き出す。
画像の場合は、ページの配置、書式、使い分けなど、見える事実まで絞る。
記事の場合は、考え方、数字、言葉のうち、一つだけを選ぶ。

### 3. 価値差分を決める

次のどれを足すか、一つだけ選ぶ。

- 驚き
- 見方の変化
- 具体的な箇所への注目
- 作り手としての確認済み情報
- 元投稿の問いへの回答
- 利用者への感謝

どれも足せない場合は、引用せず通常のリポストにする。

### 4. 文の骨格を選ぶ

#### 元投稿が詳しい場合

`[短い驚き]＋[具体的な一点]`

#### 画像の工夫へ反応する場合

`[画像内の名詞]＋[行った動作]＋[短い反応]`

#### 問いへ答える場合

`[問いへの同意]＋[確認できる一つの回答]`

#### Treowの利用報告へ返す場合

`[利用への感謝]＋[投稿内の具体的な使い方への反応]`

#### 自分の投稿へ続報を出す場合

`[前回からの変化]＋[今回見せる一つの差分]`

### 5. 人らしさを確認する

- 他の投稿へそのまま付けられないか
- 元投稿固有の名詞が入っているか
- 一文に一つの役割だけがあるか
- 感想の後に、説明を足しすぎていないか
- きれいな結論へまとめていないか
- 絵文字や崩した言葉を、型として足していないか

### 6. 公開前に確認する

1. 原稿を`marketing/x/`配下へ保存する。
2. 一般文書向けの`textlint-rule-preset-japanese`で検査する。
3. textlintのエラーを0件にする。
4. 元投稿との関係、事実、リンクを確認する。
5. Hinakaと文面を一緒に確認する。
6. 公開の直前に、対象の投稿と最終文面をもう一度確認する。

### 7. 公開後に記録する

投稿から24時間後と7日後に、次を記録する。

- 表示数
- いいね数
- リポスト数
- 保存数
- 返信数
- プロフィールへの反応
- 元投稿の形式
- Hinakaが加えた反応の種類
- 文の長さ
- 画像、URL、タグの有無

最初の10件は、絶対数だけで良しあしを決めない。
短い発見、具体的な一点、作り手の反応のうち、Hinakaに合う型を比較する。
